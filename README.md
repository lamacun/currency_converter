# Currency Converter

This project was made for learning purposes, specifically to learn to use rust.
Hence, this project is mainly made with rust.
The program is a cli-tool.

## Features
The currency converter allows for the following functionalities
+ Selection of source currency
+ Selection of target currency
+ Entering variable amounts of values
+ Portraying real time conversion rates
+ Converting given currency amounts and conversion rates
+ Handle update times
+ API & Input error handling
